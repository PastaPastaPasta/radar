One read-only explorer for the whole Dash network: Core blocks and transactions, the masternode network, and Dash Platform. These pages show the look described in docs/RADAR-DESIGN.md. Hover chips for cards, press / for search, j/k to move through tables.

  • /tx/<txid>Core transactionValue flow, settlement steps, inputs and outputs
